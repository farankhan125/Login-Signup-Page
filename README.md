# 🔐 Animated Login Signup Form

The Animated Login Signup Page is a sleek, modern, and interactive web component crafted with smooth transitions between login and signup panels, offering users an intuitive and stylish authentication experience.

---

## ✨ Features

- 🧑‍💼 Animated Login + Signup Interface
- 🔁 Seamless transition between login and signup modes
- 💻 Responsive layout for all screen sizes
- ⚡ Lightweight and easy to integrate into any project
- 🎨 Pure HTML, CSS, and Vanilla JS—no libraries

## 🚀 Getting Started

You can run this project locally in just a few steps:

1. **Clone the repository**
```bash
git clone https://github.com/farankhan125/Login-Signup-Page.git
```
2. **Navigate to the project folder**
```bash
cd Login-Signup-Page
```
3. **Open the folder in your IDE**
```bash
code -a .
```
4. **Open index.html in your browser**
```bash
start index.html
```

You're all set! ✨ No additional tools or setup required.

## 🧑‍💻 Contributing

Want to add your own style or improve the transitions? Feel free to contribute!

1. **Fork the project**  

Forking the repository is the first step to make a copy of the project under your account. Click Here: [Login-Signup Page](https://github.com/farankhan125/Login-Signup-Page)

2. **Clone your forked repository**

Make sure to replace (your-username) with your actual GitHub username, so it correctly points to your forked version.
```bash
git clone https://github.com/your-username/Login-Signup-Page.git
```
3. **Navigate into the project folder**
```bash
cd Login-Signup-Page
```
4. **Open the folder in your IDE**
```bash
code -a .
```
5. **Create your feature branch**

To make the feature name meaningful, replace your feature name with (your-new-feature-name-here) with a description of what the feature does.
```bash
git checkout -b feature/your-new-feature-name-here
```
6. **Stage the changes**
```bash
git add .
```
7. **Make your changes and commit**

Replace your commit message with (your-commit-message). The commit message should be meaningful and describe the change you made.
```bash
git commit -m "your-commit-message"
```
8. **Push to the branch**

Again, replace your feature name with (your-new-feature-name-here)

Now you can go to GitHub, where you'll see an option to "Compare & pull request." Make sure to give a clear description of what your changes do in the PR.
